学习 AI Agent 相关技术的持续笔记。

## 核心概念

- **提示词工程**：不只是写好 prompt，更是设计 Agent 的「工作说明书」
- **上下文工程**：Agent 的能力上限很大程度由喂给它的上下文质量决定
- **MCP**：给 Agent 统一的工具调用协议，类比「Agent 的 USB-C」
- **多智能体**：分工协作，但协调成本是主要矛盾

## 实践心得

- 先让 Agent 在小闭环里跑通，再扩大自主权（参考 [[项目库/OpenMontage]] 的管线思路）
- 工具调用的可靠性 > 模型的聪明程度
